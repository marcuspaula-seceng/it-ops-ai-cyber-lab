# it-ops-ai-cyber-lab

Real IT-operations processes — endpoint imaging validation, asset audit, return and
redeployment, MDM compliance, meeting-room readiness — rebuilt as read-only automation with
the security layer they originally lacked, and a local LLM that ranks and explains findings
behind deterministic guards. Sanitised: no employer name, no absolute operational figures;
only percentages already documented publicly.

```text
topicos/10-it-automation-ai/   WinOpsAudit (PowerShell 5.1, Pester 3.4, 29 tests) · Invoke-AiTriage · IntentGuard
topicos/12-it-ops-ai-cyber/    Cycles 11–16: EndpointReadiness (18) · asset audit (11) · ReturnRedeploy (15)
                               · MDM compliance (12) · rooms as office IoT (12) · CASE-05
```

Every module: `Unknown ≠ Pass`, `-WhatIf` proven, `decision: NONE`. Every AI step: output
validated for commands, change intent, invented identifiers and unverified numbers — and the
notes record the two error classes those validators cannot catch.

## What this is not

Not run in any organisation. Host runs were on the author's own machine, read-only, outputs
not committed. Synthetic CSVs and JSON throughout. Lab notes in Portuguese, as written.
